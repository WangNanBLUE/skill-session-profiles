# Security Policy

## Supported Versions

Security fixes are provided for the latest release.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability.

Use the repository's **Security** tab to submit a private vulnerability report.
Include affected versions, reproduction steps, impact, and any suggested
mitigation. Avoid attaching real Codex configuration, profile data, tokens, or
home-directory contents.

The maintainers will acknowledge a complete report as soon as practical and
coordinate disclosure after a fix is available.
